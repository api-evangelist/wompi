# Wompi

> Wompi is the payment gateway of Grupo Bancolombia, serving Colombia (COP). Its REST API (v1) creates and tracks transactions across local payment methods - CARD, NEQUI (mobile wallet), PSE (online bank debit), and Bancolombia Transfer/Collect - plus card and Nequi tokenization, reusable payment sources, and hosted payment links. Public-key endpoints are browser-safe; private-key endpoints are server-side only.

This llms.txt is generated by API Evangelist from the apis.yml catalog and repo artifacts (no first-party llms.txt is published at docs.wompi.co).

## APIs
- [Transactions API](https://docs.wompi.co/en/docs/colombia/transacciones/): Create and track payments in COP across CARD, NEQUI, PSE, Bancolombia methods.
- [Tokenization API](https://docs.wompi.co/en/docs/colombia/fuentes-de-pago/): Tokenize cards (public key) and enroll Nequi accounts.
- [Payment Sources API](https://docs.wompi.co/en/docs/colombia/fuentes-de-pago/): Store a token as a reusable payment source for later charges.
- [PSE API](https://docs.wompi.co/en/docs/colombia/metodos-de-pago/): List PSE financial institutions for online bank debit.
- [Payment Links API](https://docs.wompi.co/en/docs/colombia/links-de-pago/): Create hosted, shareable payment links.
- [Merchants & Acceptance Tokens API](https://docs.wompi.co/en/docs/colombia/tokens-de-aceptacion/): Merchant config and mandatory presigned acceptance tokens.
- [Events (Webhooks)](https://docs.wompi.co/en/docs/colombia/eventos/): Outbound HTTP POST event notifications validated by X-Event-Checksum (SHA256).
